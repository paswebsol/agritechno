# Agri-Technology Africa — Deployment-Ready Package

## Hosting
This is a static HTML/CSS/JavaScript website and can be deployed directly to GitHub Pages or Render Static Site.

### Render
- Runtime: Static Site
- Build command: leave empty
- Publish directory: `.`
- The included `render.yaml` is configured for a static deployment.

### GitHub Pages
Upload/push the contents of this package to the repository root and enable GitHub Pages from the repository's Pages settings using the branch/root folder containing `index.html`.

## Languages
- English: `index.html`
- French: `fr-index.html`
- Twi: `tw-index.html`

All language pages use flat root-level filenames to avoid folder-relative navigation problems.

## Important
The site uses external Unsplash image URLs and FormSubmit for contact forms, so an internet connection is required for those features.
